## Summary
This module introduces the foundational middleware of modern robotics: ROS 2 (Robot Operating System). It serves as the "nervous system" that connects the AI brain to the physical actuators and sensors.

## Goals
- Understand the transition from Digital AI to Embodied AI.
- Master the core communication patterns: Topics, Services, and Actions.
- Learn to build and manage ROS 2 packages using Python (`rclpy`).
- Introduce URDF for humanoid robot descriptions.

## Requirements
### Functional
- Explain the role of ROS 2 in Physical AI.
- Provide clear definitions and examples for Nodes, Topics, Services, and Actions.
- Include a guide on setting up a workspace and creating a Python package.
- Explain URDF structure for a basic humanoid.

### Non-Functional
- Tone: Educational, technical but accessible.
- Format: MDX for interactive components (if any).
- Structure: Follows the syllabus weeks 3-5 breakdown.

## Technical Details
- **Version**: ROS 2 Humble Hawksbill (LTS).
- **Language**: Python 3.10+.
- **Middleware**: FastDDS / CycloneDDS.
- **Tools**: `colcon`, `ros2cli`, `rviz2`.
