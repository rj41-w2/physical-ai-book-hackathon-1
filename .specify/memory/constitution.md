# Project Constitution: Physical AI Book

## Principles
1. **Spec-Driven Development**: Every chapter and feature must be specified before implementation.
2. **Clarity over Complexity**: Documentation should be accessible to both technical and non-technical readers.
3. **Accuracy**: Technical specifications must be verifiable and consistent.
4. **Physicality**: Focus on the intersection of AI and the physical world (Robotics, IoT, Edge Computing).

## Standards
- Use Markdown for all specifications and chapters.
- Follow Docusaurus patterns for documentation structure.
- Maintain a clear distinction between specifications (`.specify/specs`) and generated content (`docs/`).
